## 二、脚本能力架构（被测对象）

规则引擎在声明式 FEEL 之外提供 **Rhai 过程式逃生舱**，四载体共用同一沙箱求值内核（`cmx-rule-feel/src/script.rs`）：

| 载体 | 说明 | 触发形式 |
|---|---|---|
| **SC0** Rhai 接缝 | 沙箱求值内核 + `/script/eval` 端点 | `POST /script/eval {script,context}` |
| **SC1** 决策图 Script 节点 | JDM 图里的 `type:"script"` 节点 | 图 node `{lang,script}` |
| **SC2** 决策表脚本单元格 | 输出格 `=rhai:` 前缀；**判定侧仍纯 FEEL** | outputEntry `"=rhai: expr"` |
| **SC3** 脚本函数库 | 可复用 Rhai 函数，三载体皆可调 | `/functions/draft` + `/{name}/publish` |
| **SC4** 脚本决策 | `DecisionBody::Script`（`kind:"script"`） | 决策定义 `{kind:"script",lang,script}` |

**沙箱**：`max_operations`（CPU 闸门，非 wall-clock，保确定性/wasm 友好）+ 递归/字符串/数组/map 尺寸上限；无 IO/OS/时间/随机；Rhai Don't-Panic 保证错误落 trace 不崩宿主。
**数值 f64 归一**：Rhai 独立 i64/f64（`1+1`→整数），求值后递归 `normalize_numbers` 统一 f64，与 FEEL 侧 JSON 相等，保同表 FEEL 格与脚本格产等值输出。

## 四、脚本能力后端 E2E（`qa-script.sh`，55/55）

既有专项套件，直连 :8094，覆盖：

- **SC0 · Rhai 接缝**：算术/对象/字符串求值、f64 归一（`1+1`→`2.0`）、死循环沙箱拦截（`Too many operations` 带行号）、未定义函数/无限递归归因。
- **SC1 · 决策图 Script 节点**：阶梯累进个税 `income=30000 → tax=3590`；trace `input→script→output` 三节点、`nodeKind=script` 可解释；`taxable<=0` 提前 return 边界。
- **SC2 · 决策表脚本单元格**：`=rhai:` 输出格求值（`score=750 → bonus=3000`）；**判定侧 inputEntries 仍纯 FEEL，gap/overlap 分析不受脚本影响**。
- **SC4 · 脚本决策**：`kind:script` 定价 `finalPrice=117`；空脚本；完整性分析显式返回「脚本决策黑盒不参与」（非假 complete）。
- **SC3 · 函数库全生命周期**：draft（编译校验带行号）→publish（v+1）→三载体（脚本决策/`=rhai:`格/`/script/eval`）皆可调；函数间互调；未发布不注册；删除后无泄漏。
- **落库校验**：`save_draft` 经 `check_scripts` 拦图节点/脚本决策语法错，落库前暴露带行号。

> 该套件末尾**清理**临时数据（qsc_/qfn_ 前缀）。
